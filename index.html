PAT 삼각형 영상 평가 시연판 v12.14 · 연구용

휴대폰 한 대로 소아평가삼각형(PAT)의 세 축 — 호흡·외관·피부순환 — 을 객관적 수치로 기록합니다. 손에 들고 한 번 촬영하면 얼굴·몸을 자동으로 따라가며 측정합니다. 측정값만 제공하며 정상/이상 판정은 하지 않습니다.

연구·기술 검증용이며 진료 판단에 사용할 수 없습니다. 이 앱의 분석은 브라우저에서 이루어지며 영상 업로드 기능은 없습니다. 자동 영역 찾기를 누르면 외부에서 Google MediaPipe SDK·모델을 내려받습니다. 특징점 추적을 켜고 분석하면 OpenCV 코드도 다운로드합니다. Google의 SDK 안내에는 성능·사용 통계 전송이 명시되어 있습니다. 사용 통계 안내를 확인한 뒤 이용하세요. 자동 선택 없이 직접 영역을 지정할 수도 있습니다.

      5결과 — 움직임 (몸 전체)
      
    
      
    
      
    
    
      지표(개발용 정의): M(t) = 평균|추적점 변위 − 카메라(배경) 변위| ÷ (프레임 간 실제 시간 × 영역 대각선) × 100 [%/초].
    추적 실패 프레임은 선이 끊겨 표시되며 0이 아닙니다. 이 수치로 축 늘어짐·의식 저하 등 PAT 외관을 자동 판정하지 않습니다.
      
    
      
    
        
  
        

  
        
    
        5b결과 — 외관 (얼굴 표정·시선) 측정값만 · PAT 외관 판정 아님
        
    
        
    
    
        
    
        Google MediaPipe Face Landmarker의 블렌드셰이프(52개 표정 계수)와 홍채 랜드마크에서 계산한 값입니다. 눈 뜸 = 1 − 눈 깜빡임 계수, 시선 중앙 = 홍채가 눈 안 중앙(±0.15) 안에 있는 프레임 비율. 울음·의식·근긴장 판정에 쓰지 않으며, 소아에서 임상 검증되지 않았습니다.
        
  
        

  
        
    
        6결과 — 피부색 (입술·뺨)
        
    
        
    
        
    
    
        색공간 가정: 픽셀을 sRGB(IEC 61966-2-1)로 보고 선형화 → XYZ(D65) → CIELAB(D65 백색점). 자동 추적에서는 원본 영상 좌표의 아랫입술 윤곽·뺨 마스크 안에서 색을 읽고, 포화 픽셀과 밝기 상하위 10%를 제외한 RGB 평균을 변환합니다. 수동 방식은 사각형 평균을 사용합니다.
    카메라 자동 노출·화이트밸런스 등 촬영 조건 변화와 실제 피부색 변화는 이 방법으로 구분할 수 없습니다. 청색증·창백·쇼크 판정을 하지 않으며, 추적 실패·노출 불량 프레임의 값은 비워 둡니다.
    입술−뺨 차이는 해석 기준 없는 탐색용 보조값으로 CSV에만 저장됩니다.

        시험기대값실제값통과
        
      
    
        
  
        

  
        
    
        
      개발용 설정값·방법·한계
      
        
      
        방법: ROI 행 프로파일(행별 평균 밝기) 간 정규화 교차상관으로 프레임 간 수직 변위 추정 → 상·하단 배경 스트립 변위로 카메라 움직임 보정 → 변위 누적·디트렌드 → 자기상관으로 반복 주기 추정(피크 계수법 교차검증). 시간축은 영상의 실제 재생 시각(currentTime)을 사용합니다.
        
      
        한계: 호흡수 탐색 범위·모든 임계값은 임상 검증 없는 개발용 설정값입니다. 범위 밖 주기는 정상화하지 않고 '불명확/범위 경계' 사유로 보고합니다. 자기상관 피크는 신호 주기성 지표일 뿐 임상 정확도·확률이 아닙니다. '분석 불가'는 무호흡 판정이 아닙니다. 수평 방향 호흡 움직임, 심한 수기 촬영 흔들림, 보호자에게 안겨 함께 흔들리는 경우는 미검증입니다.
        
      
        움직임: ROI·배경 격자점을 7x7 블록매칭(NCC, ±5px)으로 추적. 지표 M(t)=평균|v_i−v_bg|÷(Δt×ROI대각선)×100 [%/초]. 배경 유효점 부족 프레임은 '보정 불가'로 기록되고, 유효 추적점 부족 프레임의 값은 비워 둡니다(0 아님). 이 수치로 외관·의식 판정을 하지 않습니다.
        
      
        피부색: 원본 해상도 영역 평균 RGB를 sRGB로 가정해 선형화→XYZ(D65)→CIELAB 변환. 자동 추적의 비교 기준은 2초 이상·12표본 이상·유효 비율 80% 이상 구간입니다(유효 표본 간 최대 0.5초). 부위 변경·긴 추적 공백 뒤에는 기준을 다시 모읍니다. 수동 방식의 기준은 최초 연속 2초 유효 구간 평균이며, 과다/과소 노출·포화·추적 실패 프레임은 값 없이 사유만 기록합니다. 촬영 조건(노출·화이트밸런스) 변화와 실제 피부색 변화를 구분할 수 없고, 청색증·창백 판정을 하지 않습니다. 입술−뺨 차이는 탐색용 보조값으로 CSV에만 저장합니다.
        
      
        기본 분석기의 움직임·피부색 합성 시험(정지/수평/수직/카메라만/추적실패, 변환 기준값/일정색/알려진 변화/노출/영역 이탈)은 동일 모듈을 Node.js에서 실행해 검증했습니다. 실제 피부·실제 소아 영상에서의 성능은 미검증입니다.
        
      
        v11 연속 추적: 측정 중 매 표본(약 10Hz)마다 MediaPipe Face/Pose Landmarker(VIDEO 모드)로 얼굴·자세를 다시 찾고, 배경 격자점 블록매칭으로 카메라의 이동·회전·확대(유사변환)를 추정해 가슴·배 분석 창을 함께 옮깁니다. 창은 랜드마크 영역으로 서서히 당겨지고(followAlpha), 크게 어긋나면 즉시 재고정되며 그 지점은 신호 끊김으로 기록됩니다. 외관 축은 블렌드셰이프·홍채 값만 기록하고 판정하지 않습니다. 합성 시험(Node)에서 손떨림(이동·회전·확대) 조건에 고정 창 분석은 호흡수를 절반으로 오산했고, 연속 추적은 참값을 복원했습니다 — 실제 소아·실제 손촬영에서의 성능은 미검증입니다.
        
      
        해석 규칙: interpretObservations() 독립 함수, 버전은 설정값 아래 표기. 호흡수는 WHO IMCI Chart Booklet(2014.3)의 빠른 호흡 참고 기준(2~11개월 ≥50, 12~59개월 ≥40회/분)만 사용하며, 기침·호흡곤란이 있는 소아를 안정 상태에서 1분 평가하는 맥락의 기준입니다. 색 변화 감지(ΔE76 ≥ 5, 연속 2초)는 동작 시험용 개발 설정이지 청색증·창백·순환 이상 기준이 아닙니다. 질환 확률·위험 점수·신뢰도%·SpO₂ 추정은 생성하지 않습니다. 해석 규칙의 임상 성능은 미검증입니다.
        
    
        
  
        
  
        적용한 공개 코드·검증 범위
    
        자동 선택: Google MediaPipe Tasks Vision 0.10.32, Face Landmarker + Pose Landmarker Lite, CPU, IMAGE 모드. 런타임 코드 라이선스: Apache 2.0. SDK와 모델은 CDN에서 원본을 불러옵니다.
        
    
        얼굴·관절 랜드마크에서 사각 영역을 만드는 부분은 이 앱의 개발용 기하 규칙입니다. 모델은 소아 PAT용으로 임상 검증된 모델이 아닙니다. 가슴·배는 호흡 분석용 단일 영역이며, 몸 영역은 화면에 보이는 관절 범위 후보입니다. 작은 얼굴·가림·여러 사람·옆으로 누운 자세에서는 자동 선택이 실패할 수 있습니다.
        
    
        기본 선택은 OpenCV 4.10.0의 Shi–Tomasi 특징점과 pyramidal Lucas–Kanade 흐름입니다. 호흡은 배경 보정한 흐름의 주된 방향, 움직임은 흐름 크기, 색은 주변 특징점으로 위치를 추적한 영역에서 계산합니다. 기본 JavaScript 방식도 선택할 수 있습니다. 실제 기기·소아 영상 성능 검증은 별도로 필요합니다. AIR-400 연구 코드는 영아 호흡 연구 후보이며 이 버전에는 포함하지 않았습니다. Python 모델의 모바일 변환과 별도 평가가 필요합니다.
        
    
        OpenCV.js 배포본은 @techstark/opencv-js 4.10.0-release.1로 고정했습니다. OpenCV와 배포본 라이선스는 Apache 2.0입니다. 코드 원본은 OpenCV입니다.
        카메라 프레임은 메모리에서 처리하고 저장·업로드하지 않습니다. 입력 전환·카메라 끄기·페이지 이탈·화면 숨김 때 카메라 트랙을 종료합니다. 모델을 불러오지 않으면 외부 SDK 없이 파일/수동 영역 분석을 사용할 수 있습니다.
